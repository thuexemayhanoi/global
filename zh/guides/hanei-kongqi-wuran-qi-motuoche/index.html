河内空气污染与骑摩托车：怎么看AQI

在河内骑摩托车，吸进去的就是街上的空气：汽车尾气、工地扬尘，有些日子城市上空还罩着一层看得见的雾霾。很多游客在新闻或手机应用里看到AQI数值很高，却不知道这对自己的行程意味着什么。本文介绍去哪里查看河内市的官方监测数据、怎样读懂空气质量指数和附带的健康建议、世界卫生组织对细颗粒物的说明，以及骑车时怎样减少暴露。安全骑行的其他内容，可以参阅专题页河内骑摩托车安全。

去哪里看官方监测数据

河内市有一个环境监测门户网站，市内各个监测站在上面显示当前的空气质量指数AQI（河内市环境监测门户）。每个监测站都会显示数值、等级，以及分别给一般人群和敏感人群的简短健康建议。这个指数按照越南环境总局2019年的第1459/QĐ-TCMT号决定计算（河内市环境监测门户）。数值随地点和时间变化很大，所以要看离你路线最近的监测站，而不是只看全市的一个数字。

AQI的六个等级

门户网站把数值分为六个等级（河内市环境监测门户）：

| AQI | 等级 | 门户网站的说明 | |---|---|---| | 0–50 | 良好 | 空气质量良好，对健康没有影响。 | | 51–100 | 中等 | 空气质量可以接受，但敏感人群可能会受到一些影响。 | | 101–150 | 对敏感人群不健康 | 敏感人群会出现健康问题，其他人受到的影响仍然较小。 | | 151–200 | 不健康 | 健康的人也开始受到影响，敏感人群可能出现更严重的问题。 | | 201–300 | 非常不健康 | 健康警告：所有人都可能受到更严重的影响。 | | 300以上 | 危险 | 健康警报：所有人都会受到严重影响。 |

门户网站把儿童、老年人和患有呼吸系统疾病的人列为敏感人群（河内市环境监测门户）。

看建议，不只看数字

数值下面，门户网站会分别给出针对健康人群和敏感人群的建议。2026年10月15日上午9点查看时，AQI为85，属于"中等"。当时给出的建议是：健康的人可以不受限制地进行户外活动，敏感人群可以继续户外活动，但要留意咳嗽、呼吸急促等症状（河内市环境监测门户）。建议会随着数值变化，所以除了数字，还要读一读文字说明，特别是带着孩子、年长的家人或有呼吸系统疾病的同伴出行时。

为什么一个数字不够

门户网站的地图上同时显示好几个监测点。同一时刻，地图上的数值从62到126不等，也就是从"中等"到"对敏感人群不健康"（河内市环境监测门户）。一个数值很难说明你在某个路口吸进去的空气怎么样。安排行程时，要看离路线最近的监测点；长途骑行时，路上可以再查一次。

世界卫生组织怎样说细颗粒物

世界卫生组织在关于越南空气污染的常见问题中说明，空气污染会增加呼吸道感染、心脏病、中风和肺癌的风险，短期和长期暴露都与健康影响有关（世界卫生组织驻越南办事处）。特别有害的是直径小于2.5微米的颗粒物PM2.5，它能深入肺部。同一资料给出的河内2016年PM2.5年均浓度为每立方米47.9微克（世界卫生组织驻越南办事处）。

在出现短期严重污染时，世界卫生组织建议敏感人群待在室内、减少体力活动。世界卫生组织还指出，道路交通在城市空气污染中所占的比例因城市而异，在15%到70%之间（世界卫生组织驻越南办事处）。

空气差的日子怎么安排

骑摩托车时，你就处在车流中间，经常直接吸到公交车和卡车的尾气。实用的做法有：

  • 出门前先查。看一眼门户网站，就知道今天空气好不好。
  • 空气差的日子少骑。数值到了151以上的"不健康"等级，最好推迟长途骑行，远距离改坐出租车。
  • 远离排气管。等红灯时，不要正好停在公交车或卡车的排气管后面。
  • 照顾敏感的同伴。儿童、老年人以及患有哮喘或心脏病的人，在空气差的日子不宜在摩托车上待好几个小时。
  • 留意身体的反应。咳嗽、呼吸急促或眼睛发痒，都是该停下来到室内休息的信号。

要不要戴口罩、戴哪一种，最好在出发前咨询医生，特别是本身有疾病的人。

带孩子出行时

门户网站把儿童列为敏感人群（河内市环境监测门户），所以带孩子出门的日子，标准要更严一些。即使在"中等"等级，也要看给敏感人群的建议；到了"对敏感人群不健康"等级，宁可坐出租车也不要骑摩托车。乘客和头盔的规定，可以参阅越南骑摩托车最多能载几个人。

交通、城市和低排放区

骑摩托车的人不只是在承受污染，也是车流的一部分。车况保养良好、平稳驾驶不乱加油门、短距离步行，都能起一点作用。河内市也在从交通入手采取措施。根据越南政府门户网站的报道，河内市农业与环境局介绍了一环以内低排放区的方案。报道说，从2026年7月1日起，一环以内并不是全面禁止汽油车和柴油车，而是到2026年底，在还剑郡一带的两个区域试行按车型和时段限制通行。在第一区，周五、周六和周日19点到24点，摩托车、轻便摩托车和汽车不能进入（越南政府门户网站）。从2028年起，一环以内的全部区域都将纳入，未达到第三级排放标准的摩托车和轻便摩托车将不能进入（越南政府门户网站）。这对游客意味着什么，可以参阅河内一环低排放区。

眼睛和皮肤

灰尘和废气也会刺激眼睛和皮肤。带透明面罩的头盔或一副眼镜可以保护眼睛，长袖可以保护皮肤。戴隐形眼镜的人可以带上眼药水。在城里长时间骑行之后，洗洗脸和手会舒服很多。更多装备建议，可以参阅在越南骑摩托车穿什么。

雾霾天和能见度

雾霾天不只是空气更脏，能看清的距离也更短。要放慢速度，加大和前车的距离，并确保自己容易被看见。雾霾加上下雨，路面也会变滑。相关建议可以参阅河内雨天骑摩托车注意事项，怎样应对湿冷天气可以参阅河内冬天骑摩托车。

常见问题

河内的空气是不是每天都很差？ 不是。数值随日期、时间和地点变化。我们查看的那个上午，数值属于"中等"等级（河内市环境监测门户）。看当天的数值，而不是笼统的印象。

路上觉得不舒服怎么办？ 在安全的地方停车，到室内休息，感觉好转后再继续。如果呼吸急促一直不缓解，就去看医生。

总结

河内的官方监测数据可以在市环境监测门户网站上查到；AQI达到101以上时敏感人群会受到影响，达到151以上时其他人也会受到影响（河内市环境监测门户）。根据世界卫生组织的说明，PM2.5特别有害，严重污染时最好待在室内并减少体力活动（世界卫生组织驻越南办事处）。出门前先查指数，空气差的日子少骑，照顾好敏感的同伴。
