半自动挡摩托车怎么骑：本田Wave不用离合器的换挡方法

以本田越南公布的Wave Alpha使用说明书为依据，讲解半自动挡摩托车的骑法：启动步骤、停车和行驶时不同的换挡方式、换挡前收油门、降挡的速度上限、下坡用发动机制动，以及需要哪一类驾照。

在越南的街道上，像本田Wave（Wave Alpha）这样的半自动挡摩托车几乎和自动挡踏板车一样常见。越南人把它叫作"xe số"，意思是带挡位的摩托车。它用脚换挡，但车把上没有离合器手柄。只骑过踏板车的人，最先遇到的难题往往就是换挡。本文以本田越南公布的使用说明书为依据，依次说明怎样启动、换挡、减速停车和上下坡。车型选择的整体思路，可以先看河内租摩托车如何选择车型这个专题页。

什么是半自动挡

带离合器的手动挡摩托车，要用左手捏离合器、用脚踩换挡踏板，两者配合才能换挡。自动挡踏板车则完全没有换挡操作。半自动挡介于两者之间：有挡位，却没有离合器手柄，骑手只需要操作油门和换挡踏板。本田越南的说明书把Wave Alpha的变速箱描述为四个前进挡（本田越南，Wave Alpha使用说明书）。

根据本田越南的产品页面，Wave Alpha 110排量为109.2cm³，最大功率6.12kW，配备四挡循环式机械变速箱，整车质量96kg，使用17英寸轮胎（本田越南）。它轻巧好操控，但操作逻辑和踏板车很不一样。它和其他车型的区别，可以参考手动挡与自动踏板车怎么选和本田Wave、Vision、Air Blade车型比较。

出发前先认清操作部件

拿到车后，先确认下面这些部件在哪里、怎么用：

  • 油门： 右手把手。
  • 刹车： 前刹是右手的刹车手柄。不要想当然地认为后刹和踏板车一样在左手，当场问清楚后刹在哪里操作。
  • 换挡踏板： 用脚踩的换挡踏板。
  • 燃油开关： 说明书要求正常骑行时放在ON，停放、存放或运输时放在OFF。
  • 指示灯： 空挡时亮起的N指示灯，以及显示1至4挡的挡位指示（说明书）。
  • 启动装置： 电启动按钮、脚踩启动杆，以及天冷时用的阻风门拉杆。

踏板往哪个方向踩是升挡、往哪个方向踩是降挡，最稳妥的办法是取车时请工作人员当面示范一次。

启动步骤

气温在10至35°C之间时，说明书给出的步骤如下（本田越南）：

1. 确认燃油开关在ON位置。 2. 把钥匙转到ON。 3. 挂入空挡（N指示灯亮）。 4. 把阻风门拉杆拉到底，置于ON。 5. 略微拧开油门，按下电启动按钮。用脚踩启动杆时，先轻踩到感觉有轻微阻力，让它回到最高位置，再略开油门，从上往下快速有力地一踩到底。 6. 发动机一着车，立即把阻风门推回一半，轻轻开合油门暖车。 7. 大约半分钟后，把阻风门完全推回OFF。

气温达到35°C或以上时不用阻风门，把油门拧开约1/8至1/4再启动。如果按电启动5秒内没有着车，就把钥匙转到OFF，等10秒再试，让电瓶电压恢复。说明书还提醒：行驶中不要踩启动杆；长时间怠速或不停地轰油门，会损伤发动机和排气系统。

变速箱的原理：停车和行驶时不一样

Wave Alpha有四个前进挡，停车时和行驶时的换挡方式不同。车停着的时候，变速箱按"循环式"工作，可以从4挡直接换到空挡；车在行驶时，变速箱按"往复式"工作，不能从4挡直接换到空挡（说明书）。可以把它理解为一种防止行驶中误挂空挡的设计。

现在挂的是几挡，看仪表上的挡位指示就知道。停车时N指示灯亮着，就是空挡。刚开始骑的时候，每换一次挡都瞄一眼指示，很快就会养成习惯。

换挡的三条规则

说明书强调了三点（本田越南）：

  • 换挡前一定要先收油门。
  • 用脚尖轻踩换挡踏板，直到踏板被踩到底。
  • 避免不必要的换挡，骑行时不要把脚搁在换挡踏板上。 否则可能损坏换挡机构和离合机构。

实际骑起来就是一个固定的节奏："收油门、踩踏板、再慢慢给油"。如果开着油门换挡，车身会猛地一顿。

起步和升挡

1. 发动机运转后，捏住前刹，在油门关闭的状态下挂入1挡。 2. 按说明书的要求打转向灯，确认周围没有驶来的车辆（本田越南）。 3. 松开刹车，慢慢拧油门起步。 4. 车速起来后收油门换2挡，再用同样的方法换3挡、4挡。

什么时候该升挡，答案在速度表上。速度表上的"各挡位速度范围"标示了每个挡位的速度上限，说明书要求在超过上限之前升到高一挡；超过上限再升挡，可能损伤发动机（说明书）。取车时最好让人指给你看这个标示在速度表的哪个位置。

降挡的速度上限

说明书用一张表列出了降挡时的允许速度（本田越南）：

  • 4挡降3挡：80km/h或以下
  • 3挡降2挡：55km/h或以下
  • 2挡降1挡：30km/h或以下

高于这些速度降挡，发动机转速会过高，可能损伤发动机和变速箱。

刹车与停车

刹车时先收油门，前后刹同时使用。避免急刹和突然降挡，进弯前就把速度降下来（说明书）。接近红绿灯时，随着车速下降逐挡降下来。要停较长时间，就挂空挡并确认N指示灯；马上要走的话，一般的做法是留在1挡，捏住前刹等待。刹车技巧可以参考骑踏板车怎么刹车。

上坡、下坡和山路

说明书说明，松开油门时发动机制动会让车减速，想再慢一些就降挡。在又长又陡的下坡上一直捏着刹车，刹车会过热、效果变差，所以应当把发动机制动和间歇刹车结合起来控制车速（本田越南）。上坡时要在发动机吃力之前提前降到低挡。山路急弯的骑法见越南山路急弯怎么骑，各类道路的限速见越南摩托车限速。

新手常犯的错误

  • 不知道自己在几挡： 养成看挡位指示的习惯。
  • 开着油门换挡： 冲击大，也伤机构；一定先收油门再踩。
  • 把脚搁在换挡踏板上骑： 说明书明确要求避免。
  • 车速太快就降挡： 遵守上面的速度上限。
  • 停车后不看挡位就起步： 先看N指示灯和挡位指示再走。
  • 找错后刹的位置： 出发前务必确认。

分阶段练习

找一个车少、宽敞的地方，循序渐进地练。先练启动和确认空挡，再反复练1挡起步和停车。熟练后练1挡和2挡之间的切换，接着是3挡、4挡，停车前的降挡，最后是缓坡起步和下坡时的发动机制动。等到不看脚下也能换挡，再上车多的道路。想先从自动挡开始熟悉的话，可以看第一次骑自动挡踏板车；想挑战离合器摩托车，可以看离合器摩托车怎么骑。

需要什么驾照

Wave Alpha的排量是109.2cm³，在越南需要A1驾照，也就是排量125cm³以下两轮摩托车的驾照。驾照等级按排量（电动车按电机功率）划分，不按变速方式区分（《道路交通秩序与安全法》（第36/2024/QH15号法律）第57条第1款a点）。没有有效驾照驾驶125cm³以下的摩托车，按第168/2024/NĐ-CP号议定第18条第5款a点处2,000,000至4,000,000越南盾罚款。中国驾照能不能在越南骑车，见中国驾照能在越南骑摩托车吗。

加油和带人

根据说明书，越南版Wave Alpha使用无铅汽油，按辛烷值（RON）91或以上设计，油箱容量为3.7升（本田越南）。油箱小，长途骑行的日子要早点加油。加油口在坐垫下面。

带人时，说明书要求乘客扶住骑手的腰或后扶手，过弯时和骑手一起倾斜身体，停车时也要把脚放在脚踏上（说明书）。换挡还不熟练时，先自己练好再带人。后座乘客的注意事项见在越南坐摩托车后座。

常见问题

只骑过踏板车，能骑半自动挡吗？ 不用操作离合器，要学的东西比手动挡少。不过上车多的路之前，还是要先在安静的地方把起步、停车和换挡练熟。

和踏板车用同一种驾照吗？ 排量125cm³以下的话，踏板车和半自动挡都是A1（第57条第1款a点）。

可以挂着挡启动吗？ 说明书的步骤是先挂空挡、确认N指示灯亮了，然后再启动（本田越南）。

小结

半自动挡摩托车没有离合器手柄，只靠脚踏板在四个挡位之间切换。在空挡启动，换挡前一定先收油门，降挡不要超过说明书给出的速度。长下坡时，把发动机制动和间歇刹车结合起来使用（本田越南，Wave Alpha使用说明书）。

出发前，可以用河内租摩托车取车检查确认刹车和灯光。
