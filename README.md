# Vietnam Two-Wheel Guide · Global

Production website: https://global.rentbikehanoi.com/ · GitHub Pages repository: https://github.com/thuexemayhanoi/global

One GitHub Pages site with ten locale directories: `/vi/`, `/en/`, `/de/`, `/fr/`, `/es/`, `/nl/`, `/zh/`, `/pt/`, `/ko/`, `/ja/`. Every page is server-rendered static HTML generated by `scripts/build.mjs`; the language switcher links to real HTML, not client-side translation.

## How content is produced today (effective 2026-10-15)

```
Topic Factory → shared topic queue → W1/W2/W3 external AI Writers → Writer QA
   → SUBMITTED (immutable SHA-256) → automated QA G1–G5 + G7
        ├─ fixable FAIL → repair ticket → same Writer writes r2/r3/r4 → QA again
        ├─ LEGAL / SAFETY / PRICE / money → held for a human
        └─ PASS → Auto Publisher: 2 NEW URLs per run → GitHub Pages → Live QA → next 2
```

- **Writers W1/W2/W3** are three seats for external AI sessions (Claude, ChatGPT, Gemini or any agent with repository access and quota). They write concurrently from one shared queue, up to 10 claims each, never the same ID.
- **QA is Node.js on GitHub Actions only.** There is no AI Reviewer, no AI API, no self-hosted model and no secret besides `GITHUB_TOKEN` (enforced by `tests/no-ai-api.test.mjs`).
- **GitHub Actions does not write text.** Drafts and repairs exist only while an external AI Writer session is active. Automatic parts: claims and refills, QA, repair tickets, publication of eligible drafts, Live QA and the drain to the next pair.
- **Publication**: the standing-policy Auto Publisher (`approvals/standing-policy-20261015.json`) publishes at most two new URLs per run and starts the next pair only after Live QA passes. A Live QA FAIL reverts and pauses; an INCONCLUSIVE result pauses without touching production; resuming needs a confirmed dispatch. The manual owner-manifest path (`scripts/seo/publish-batch.mjs`) still exists.

## Regenerate and verify

- `node scripts/build.mjs` regenerates HTML, robots and the sitemap index/shards from the source data.
- `node scripts/build.mjs --check` validates generated outputs without changing files (also runs on GitHub Actions).
- Generated HTML is committed in the repository root for the existing GitHub Pages branch deployment; do not change the Pages source without a separately reviewed migration.
- Full QA: `node --test tests/*.test.mjs`, `node scripts/seo/validate-plan.mjs`, `node scripts/seo/seo-guard.mjs`, `node scripts/seo/fact-guard.mjs`, `node scripts/seo/content-graph.mjs --check`, `node scripts/nav-qa.mjs`.

## SEO policy

- Each URL has one search intent and an explicit locale.
- Locale homepages and corresponding checklist pages use self canonical + hreflang equivalents. New, genuinely distinct topics get no hreflang unless real equivalents exist.
- Sitemaps list only real published pages; never empty category stubs. Live URLs, their SEO fingerprints and CNAME (`global.rentbikehanoi.com`) are protected (`data/seo/url-freeze.json`).
- No speculative prices, legal claims, reviews, availability or business details; Nguyễn Tú facts come only from `data/business/reference.json`.
- Never import or overwrite WordPress or /lab projects.
